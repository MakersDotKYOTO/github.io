追加機能 v2.3:
- 初詣競技にストップウォッチを追加
- Team選択 → START → GOAL・保存
- GOAL時に0.01秒単位でタイム欄へ自動保存
- GOAL時に完走を自動ON
- 保存後、完走タイム順位とタイム順位点を即時再計算
- RESETは現在の計測表示のみを初期化し、保存済み競技結果は消さない
- 手入力によるタイム修正も従来どおり可能

追加機能 v2.4 - ヒューマンエラー防止:
1. 初期状態では全Teamの初詣採点入力をロック
2. 一覧から入力対象Teamを「選択」
3. 選択Teamを緑色で強調表示
4. 選択Teamの入力欄だけ操作可能
5. 他Teamはグレー表示・入力禁止
6. START / GOAL は選択Teamだけに紐付く
7. 計測中はTeam変更・選択解除不可
8. GOAL・保存後、「選択解除・次のTeamへ」で明示的に切り替え

追加機能 v2.5 - 次Team自動選択:
- 選択中Teamの次の有効Teamを自動判定
- ボタンに「次：B / BRAVO（ブラボー）」のように次の対象を表示
- ボタンを押すと、現在Teamの選択を解除して次Teamを即時選択
- 次Teamだけ入力・計測可能になり、その他はロックを維持
- 最後のTeamでは先頭へループせず「全Team終了・選択解除」
- 計測中は次Teamへ進めない

追加機能 v2.6 - 強制選択・修正:
- 他Teamが選択されている状態でも、ロック行に「強制選択」ボタンを表示
- 強制選択時は確認ダイアログを表示
- 確認後、修正対象Teamへ選択を切り替え
- 保存済みデータは消去しない
- 修正対象以外のTeamは引き続きロック
- 計測中は強制選択不可
- 通常運用では従来どおり「次：○○」で自動進行可能
